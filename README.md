# 祝日の由来

1年に16ある国民の祝日の、日付・日の決め方・祝日法に書かれた意味（「年のはじめを祝う。」など）と、振替休日などの休みのきまりを当てる1日5問のゲームです。知らなくても、まちがえながら覚えられます。

- 遊ぶ：<https://satou-aaaaa.github.io/shukujitsu-yurai/>
- 今日の5問はだれでも同じで1日1回。とことん・練習は何度でも遊べます。時間制限はありません。
- 記録は遊ぶ人のブラウザの中だけに残り、外へは送りません。

## 出典

- 祝日の日付・意味・休日のきまり：内閣府「国民の祝日」について <https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html> （国民の祝日に関する法律 第2条・第3条）
- 法律の文：e-Gov 法令検索「国民の祝日に関する法律」 <https://laws.e-gov.go.jp/law/323AC1000000178>
- 昔の日付・名前（成人の日は前は1月15日、体育の日は10月10日など）：英語版 Wikipedia「Public holidays in Japan」 <https://en.wikipedia.org/wiki/Public_holidays_in_Japan>
- 第○月曜日・振替休日の日付は、祝日法のきまりでコードが計算しています。
